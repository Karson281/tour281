# 香港旅行團性價比顧問（廣東/廣西短線）

跨旅行社 CP 比較互動網頁 —— 3 間旅行社、587 個旅行團（3-4 天巴士/高鐵 + 1-2 天廣東短團）。

## 功能

- 🏆 **跨旅行社 CP 比較**：同類團（地區 + 天數 + 交通）自動分組，並排顯示各旅行社最低價，綠色標示「最抵」
- 🔍 快捷編碼搜尋：例如 `A3C6+BC`（中國 + 3天 + 高鐵 + 6月 + 五星純玩/美食）
- 🎚️ 逐步點選篩選：目的地 / 天數 / 交通 / 月份 / 偏好
- 💰 含導遊費實際總價計算
- 📱 純靜態網頁，手機平板都用到
